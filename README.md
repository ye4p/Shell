# tny Shell

Supported features:

*Pretty much standard, but slightly limited syntax of linux shell (closest to bash), besides few exceptions:

cmd > file
cmd >> file
cmd >& file
cmd >>& file

Are all legal in this shell, whereas >>& syntax is illegal in traditional shells. Input redirection is also supported and it is standard.

*Piping with

| and |&

is fully supported.

*Logical Operators

&& and || 

do work.

*Quotations

Also supported, both ' and "
